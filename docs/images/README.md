# Current interface captures

Only the latest available native Android capture set is used in this README:
**Build 191 development, 26 October 2026**. Older interface revisions are deliberately
excluded from this presentation.

| Image | What it shows | Evidence boundary |
| --- | --- | --- |
| [Frying](frying.png) | Fixed upper vessel area, time / temperature controls, stirring choices and the lower function strip | Development / emulator UI; the new motor-interval behavior had not been physically validated |
| [Cleaning guidance](cleaning.png) | Program explanations within the current interface | Development / emulator UI; displayed settings are not evidence of a completed real cooking trial |

The PNGs are copied without cropping, retouching or generated screen content.
[The manifest](manifest.json) records source archive, capture date and SHA-256.
The original filenames are `frying-choices.png` and `cleaning-information.png`.

These captures show the full development build. The minimal public application
source omits manufacturer artwork and mixed-origin photographic / 3D assets and
uses schematic fallbacks. This gallery documents the interface design; it is not
a screenshot acceptance test of a freshly built public APK. Simulated device
state is not presented as live physical telemetry.

Screenshots are supplied to illustrate this project's interface. Depicted product
imagery and third-party marks retain their respective rights; they are not
relicensed as standalone assets under the repository's MIT code license.
